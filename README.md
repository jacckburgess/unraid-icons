# unraid-icons

Icons for my Unraid containers. Unraid fetches the icon URL without auth, so they live here in a public repo.

Icon URL:

```
https://raw.githubusercontent.com/jacckburgess/unraid-icons/main/icons/<name>.png
```

Icons are 512x512 PNGs. Unraid caches them, so after replacing one either re-apply the container or delete the cached copy in `/var/lib/docker/unraid/images/`.
